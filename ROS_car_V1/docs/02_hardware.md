# 硬件接线与底盘参数

本表从当前 `Core/Src`、头文件和 `.ioc` 提取，用来核对复刻接线。它描述固件实际使用的信号，不代替整车原理图或电源设计；当前资料没有 PCB、连接器针序和完整 BOM。

## 1. 主控、时钟与供电

| 项目 | 当前工程 |
|---|---|
| MCU | STM32F405RGT6，Cortex-M4F |
| 系统时钟 | 168 MHz |
| HSE | 8 MHz 外部高速晶振，`HSE_ON` |
| LSE | 初始化启用外部低速晶振，正常配置为 32.768 kHz |
| APB1 / APB1 定时器 | 42 MHz / 84 MHz |
| APB2 / APB2 定时器 | 84 MHz / 168 MHz |
| 链接布局 | FLASH 1 MiB；主 SRAM 128 KiB；CCM 64 KiB 单独定义 |
| GPIO/串口/SWD 逻辑 | 按 3.3 V 接口接线 |

`SystemClock_Config()` 同时请求 HSE 和 LSE；复刻板若没有相应晶振，可能在时钟初始化阶段进入 `Error_Handler()`。不要只把芯片型号换成 F405 就假设时钟电路相同，应同步修改时钟树及 `HSE_VALUE`。运行期间的时序测量依赖正确的内核时钟。

CCM 的存在不代表 DMA 可以使用它。当前 DMA 缓冲使用普通 SRAM，不要随意将 UART/OLED/灯带 DMA 缓冲迁入 CCM。

## 2. DAPLink 的 SWD 接线

| 信号 | MCU 引脚 |
|---|---|
| SWDIO | PA13 |
| SWCLK | PA14 |
| NRST | NRST 引脚 |
| GND | GND |
| 电压参考 | 目标板 3.3 V，具体按探针接口说明 |

工程有 PA15/PB3 等复用引脚用于编码器。使用 SWD 两线方式调试，不要把它切回占用这些脚的完整 JTAG 接线。烧录教程见 [VS Code＋DAPLink](01_vscode_daplink.md)。

## 3. RDK X5 串口

| STM32 USART3 | 接到上位机 |
|---|---|
| PB10 / TX | RDK 使用的 UART RX |
| PB11 / RX | RDK 使用的 UART TX |
| GND | RDK GND |

参数为 **115200、8 数据位、无校验、1 停止位，无硬件流控**。使用 3.3 V TTL UART，不直接接 RS-232 电平。RDK 扩展口的物理针脚和设备节点应查对应板卡资料，这份 STM32 工程不能确定你选择了 RDK 的哪一路串口。

STM32 启动校准结束后，约每 20 ms 发送轮速和 IMU 两帧。命令不是 `cmd_vel` 文本，而是 [RDK 二进制协议](rdk_uart.md) 中的 `0x03` 四轮目标角速度帧。

## 4. ELRS 接收机

| STM32 UART5 | 接收机 |
|---|---|
| PD2 / RX | 接收机 CRSF TX |
| PC12 / TX | 接收机 CRSF RX（当前主要使用通道接收） |
| GND | 接收机 GND |

参数为 **420000、8N1**，接收机应输出 CRSF，而不是 SBUS、PWM 或 PPM。接收机供电电压按具体型号和电路供电，不由 UART 逻辑电平推断。

通道分配为 CH1 左右平移、CH2 前后、CH4 转向、CH5 总解锁、CH6 模式、CH8 报警。低/中/高原始值约 172/992/1811；实体开关方向由遥控器混控与反向设置决定。详细阈值和切换步骤见 [运行时控制](runtime_control.md)。

## 5. 四轮电机和编码器

所有对外协议统一使用 **FL、FR、RL、RR＝左前、右前、左后、右后**。下表的数组顺序等于 `Motor_ID_t`，不要因旧接线注释中的 motor1/motor2 编号而重新排序。

| 数组索引 | 轮位 | PWM | 方向 GPIO | 编码器 A/B | 输出符号 / 编码器符号 |
|---:|---|---|---|---|---|
| 0 | 左前 FL | PA3，TIM5_CH4 | PB1 | PA15/PB3，TIM2_CH1/2 | −1 / +1 |
| 1 | 右前 FR | PA1，TIM5_CH2 | PA5 | PB4/PB5，TIM3_CH1/2 | +1 / −1 |
| 2 | 左后 RL | PA2，TIM5_CH3 | PC4 | PC6/PC7，TIM8_CH1/2 | −1 / +1 |
| 3 | 右后 RR | PA0，TIM5_CH1 | PA4 | PB6/PB7，TIM4_CH1/2 | +1 / −1 |

当前电机驱动接口使用 PWM＋方向信号，符号修正在 `Motor.c` 的 `motor_config[]`。应接到与该控制方式匹配的电机驱动级，不把电机直接接到 MCU 引脚。代码中存在历史驱动芯片注释，实际器件选型应以电路为准。

TIM5 PWM 计数周期为 4199，在 84 MHz 定时器时钟下约 **20 kHz**。对内占空比接口范围是 −10000～10000，随后换算为定时器比较值；它不是 cps，也不是 rad/s。当前零 PWM、方向脚复位对应关驱动输出，不能据此承诺机械上立即刹停。

编码器每轮一圈按 **1333 个实际解码计数**换算；这里不是单独给出的编码器线数。复制到不同减速比/编码器时，需要测量输出轮转一整圈的总计数，再同步修改测速和里程计参数。

## 6. IMU 和外围器件

| 器件/功能 | 总线及引脚 | 当前用途 |
|---|---|---|
| LSM6DSR | SPI2：PB13 SCK、PB14 MISO、PB15 MOSI；PC0 CS；PC8 INT | 104 Hz 陀螺仪和加速度，主循环读取新数据位 |
| LIS3MDL | 共用 SPI2；PC1 CS；PB12 DRDY | 代码仍初始化；当前姿态融合不使用磁力计 |
| OLED 128×64 | I2C1：PB8 SCL、PB9 SDA；7 位地址 0x3C | 默认熄屏，旋钮按键开启，DMA 分片刷新 |
| INA219 | 共用 I2C1；7 位地址 0x40 | 电压、电流监测，当前电流标定按 10 mΩ 分流电阻 |
| MB85RC64T FRAM | 共用 I2C1；7 位地址 0x50 | 保存 PID 参数；不是 MCU 内部 Flash |
| 旋钮 A/B | PC9 / PC5，即 KEY1 / KEY2 | 菜单移动和编辑 |
| 旋钮按键 | PC2，即 KEY3，低电平按下 | 开屏、进入、返回 |
| 用户 LED | PC13，低电平有效 | 周期状态灯 |
| 蜂鸣器 | PC3，高电平有效 | 启动、解锁和报警节奏 |
| WS2812B 灯带 | PB0 / TIM1_CH2N | DMA 灯效 |

I2C1 配置为 400 kHz。器件地址表使用 **7 位地址**；HAL 调用中传入的地址会左移一位，不要把两种写法混用。SCL/SDA 上拉、供电和地应与实际硬件匹配。

陀螺仪量程 ±250 dps，对应 0.00875 °/s/LSB；加速度量程 ±2 g，对应 0.000061 g/LSB。更改寄存器量程后，必须同步修改 `rdk_uart.c` 和校准处的单位换算。IMU 安装坐标与车体坐标也要一致；固件未替你添加任意安装方向的旋转矩阵。

USART1 当前不初始化/不启用接收。UART4 的无线 VOFA 发送由 `VOFA_WIRELESS_ENABLE=0` 关闭。CAN 的初始化文件保留，但不承担本项目 RDK 底盘控制协议。

## 7. 几何和速度参数

| 参数 | 值 | 源码位置 |
|---|---:|---|
| 轮半径 | 0.04 m，即 40 mm | `Odom.c` 的轮径 0.08 m |
| 轮周长 | 0.251327412 m | `ODOM_WHEEL_CIRCUMFERENCE_M` |
| 每输出轮一圈计数 | 1333 | `Odom.c`、`rdk_uart.h` |
| 前后轮中心距离 | 0.167 m，即 167 mm | `2 × ODOM_HALF_LENGTH_M` |
| 左右轮中心距离 | 0.188 m，即 188 mm | `2 × ODOM_HALF_WIDTH_M` |
| 运动学转动系数 L＋W | 0.1775 m | 两个半距相加 |
| 手动每轮混合后上限 | 1000 cps | `DRIVE_REMOTE_WHEEL_LIMIT_CPS` |

这些是当前软件配置，**不是车身外廓尺寸，也不是本次重新标定的实测值**。按上述半径和计数，1000 cps 的直线轮缘速度约 0.1885 m/s。硬件变化时，上下位机的半径、轮距、轴距和计数必须同步，否则四轮能闭环也不代表里程计和导航正确。
