# Mahony 六轴姿态与串口集成

## 方案

本工程采用 Mahony 非线性互补滤波的六轴实现：三轴陀螺仪负责姿态传播，加速度计提供重力方向观测，比例/积分反馈修正可观测的姿态误差和残余零偏。算法参考 [Mahony 等人的原始论文](https://doi.org/10.1109/TAC.2008.923738)；本工程根据以下坐标约定编写实现，没有引入额外库。

当前 LSM6DSR 已配置为 104 Hz、±250 dps、±2 g，主循环约每 10 ms 读取一次新采样，滤波使用两次新陀螺仪采样之间的实际毫秒差，串口每 20 ms 发送一次最新结果。算法只在主循环运行，不在串口、电机或 SysTick 中断内执行。

选择六轴的原因是现有工程没有提供 LIS3MDL 的硬铁/软铁校准和与加速度计轴系的对齐参数。当前输出为启动时相对航向，不宣称指北。日后补齐磁力计校准后，可在相同接口下扩展九轴航向校正。

## 坐标与数学约定

- 所有传感器量采用同一右手传感器坐标系，没有擅自换轴。
- 世界坐标系 z 向上。四元数 `q=(qx,qy,qz,qw)` 将传感器坐标向量旋转到世界系：`v_world = q ⊗ v_sensor ⊗ conjugate(q)`。
- 角速度为 rad/s，正方向遵循右手定则；加速度为加速度计比力，m/s²，不预先去重力。z 向上静止时 az 约 +9.81。
- 姿态初始 yaw=0，roll/pitch 来自静止重力方向。串口沿用 xyzw，不能按某些库的 wxyz 顺序发送。
- 主界面及原航向控制用 `atan2(2(qw*qz+qx*qy), 1-2(qy²+qz²))` 从同一份四元数计算 yaw。

核心步骤：

```text
1. 新原始采样 -> 三轴零偏补偿 -> 物理单位。
2. 由四元数求传感器系中的预测重力方向 v = R(q)^T [0,0,1]。
3. 将加速度归一化为 a，计算方向误差 e = a × v。
4. 可信时更新有界积分项，并计算 omega = gyro + Kp*weight*e + integral。
5. 用四元数指数更新 q <- q ⊗ delta_q(omega, dt)，然后归一化。
6. 将新的 xyzw、角速度、加速度一起装入现有 0x91 帧。
```

采用四元数传播，因此不会因为欧拉角在俯仰接近 90° 时出现奇异而中断解算；界面显示的欧拉 yaw 在该姿态附近仍存在欧拉角本身的歧义。

性能优化后，半转角不超过 0.05 rad 时使用四阶 sinc/cos 近似，误差低于 float32 精度；较大转角保留 sqrtf/sinf/cosf 路径。滤波器仍逐次归一化。可信内部结果直接写入串口缓存，外部输入保留范围/NaN/Inf/模长检查，使用 float/sqrtf；打包不再重复归一化内部已验证结果。三轴、组合旋转和变采样间隔测试覆盖两条传播分支。

## 启动与数据有效性

上电建议保持小车静止约 **5 秒**，以有效位/OLED 诊断状态为准。

1. 保留约 3 秒启动校准尝试。`imu_calibration.c` 要求至少 200 个新陀螺仪采样覆盖至少 2 秒，资格检查允许使用 30 ms 内独立到达的加速度，模长须在 0.95～1.05 g。各轴原始值绝对值须不超过 600 LSB，使用 float32 Welford 方差检查，标准差不超过 50 LSB。
2. 校准成功后调用 `RDK_UART_SetGyroBiasRaw(x,y,z)`，启用自动姿态解算。启动未成功时，主循环在四轮目标均为零、速度均在 ±10 cps 内时继续尝试；运动/异常会清除候选窗口，退避 250 ms。校准未成功时，原始物理量仍可上传，四元数保持无效。成功的零偏保持锁定，不在行驶中更新。
3. 滤波器继续收集 **32 个新的近静止采样**：加速度 0.95～1.05 g、补偿后角速度模长不超过 0.10 rad/s，累计重力方向须一致。初始化时缺少加速度且间隔不超过 30 ms，只暂停累计；不重用观测、不提前标为有效。更长缺失、检测到运动或异常读数仍清除窗口。正常约 0.32 秒；采样不同时到达时可能更长。由平均重力初始化 roll/pitch，yaw=0，随后标为有效。
4. 校准只能在实际静止时执行。恒定的慢速转动与陀螺仪零偏无法仅凭静止校准数据区分，不能靠上述方差门限识别全部运动。

滤波器每次只处理新陀螺仪采样。没有新陀螺仪就不产生新姿态，不以重复旧四元数刷新有效位。丢失加速度时可短时仅用陀螺仪预测；加速度超过 200 ms 没有新采样时，四元数不再标为有效。

新陀螺仪间隔超过 **50 ms**、输入角速度非有限或采样间隔异常时，滤波器丢弃无法可靠衔接的姿态，重新等待静止对准。这时 yaw 会以重新对准的时刻为零，属于新的相对航向参考。消费者应检查有效位，不能把采样中断前后的参考视为无缝连续。

## 默认参数与动态抑制

参数在 `Core/Inc/imu_attitude.h`，算法在 `Core/Src/imu_attitude.c`：

| 参数/策略 | 默认值 | 用途 |
|---|---:|---|
| Kp | 2.0 | 重力方向比例校正 |
| Ki | 0.05 | 估计可观测的残余陀螺仪偏差 |
| 积分修正限幅 | 每轴 ±0.05 rad/s | 避免积分失控 |
| 最大单次采样间隔 | 50 ms | 不跨越长时间采样空洞积分 |
| 姿态初始化 | 32 个近静止采样 | 可靠初始化 roll/pitch |
| 加速度置信度 | 1 g 时为 1，偏离 ±0.15 g 时降为 0 | 冲击/自由落体时抑制重力校正 |
| 方向创新门限 | 30° | 拒绝明显矛盾的加速度方向 |
| 积分更新条件 | 加速度接近 1 g、角速度小于 0.10 rad/s | 减少运动时积分污染 |

加速度受运动影响时，滤波器减弱或停止重力修正，继续进行陀螺仪传播。幅值与方向门限不能区分所有持续线加速度和真实倾斜，实车快速加速、急刹与振动下仍需调参验证。

六轴系统没有绝对航向观测。即使 roll/pitch 稳定，yaw 仍会因剩余 Z 方向零偏长期漂移；积分反馈无法凭重力消除这一不可观测方向。该问题需经过校准的磁力计或其他外部航向参考解决。

## 串口输出

协议、长度、CRC 和字节位置保持原文件约定：

```text
AA 55 91 | qx qy qz qw | gx gy gz | ax ay az | flags | CRC_LO CRC_HI
          4个float32    3个float32  3个float32
```

| flags | 含义 |
|---|---|
| 07 | 本次姿态、角速度、加速度均有效 |
| 06 | 姿态校准/初始化/重对准中，角速度和加速度有效 |
| 03 | 新角速度支持短时姿态预测，加速度无新采样 |
| 04 | 只有加速度可用，没有新姿态 |
| 00 | 本次无可用数据 |

`RDK_UART_UpdateImuRaw()` 自动调用滤波并提交四元数。`RDK_UART_GetOrientation()` 提供同一份姿态快照给界面/航向控制；已经发送不影响读取，但无效或超过 50 ms 的快照返回 0。`RDK_UART_UpdateOrientation()` 保留为外部 AHRS 覆盖接口，正常流程无需手动调用。

## 验证

```powershell
cmake --build --preset Debug --parallel 4
powershell -NoProfile -ExecutionPolicy Bypass -File tests/rdk_uart/run_tests.ps1
```

原生测试编译实际 C 算法，使用独立的双精度旋转轨迹生成传感器真值。覆盖静止、倾斜和倒置初始化；三轴和组合旋转；变采样间隔；重力反馈收敛；积分限幅；异常加速度/自由落体；无效输入；长时间归一化以及六轴航向不可观测性。

集成测试直接输入原始陀螺仪/加速度采样，验证自动解算静止四元数和正向 90° 航向，再将实际串口发送缓冲区交给桌面的原始 `x5car_protocol.cpp` 解析，检查姿态顺序、旋转方向、归一化、07/03/04 标志、校准门控和中断后重对准。

这些是算法与协议的软件验证，不代表实车精度测试。当前尚未烧录或测量实际姿态误差。
